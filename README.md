# Saffron House Template

Build a premium, mobile-first digital QR menu website template for a fictional Kuwait restaurant called "Saffron House".

IMPORTANT:

This is a reusable template that I will later customize for many different restaurants. Keep the code clean, simple, and easy to edit. Do NOT build a SaaS dashboard or complicated backend.

DESIGN:

- Luxury modern restaurant aesthetic

- Black / warm cream / subtle gold accents

- Beautiful large food photography

- Elegant typography

- Rounded cards

- Smooth animations, but keep the website fast

- Designed primarily for customers opening it from a QR code on their phone

- Excellent mobile layout

- Also responsive on desktop

HEADER:

- Restaurant logo placeholder

- Restaurant name: Saffron House

- Arabic / English language toggle

- Small location text: Kuwait

HERO:

- Large premium restaurant food image

- Short tagline

- "View Menu" button

- "Order on WhatsApp" button

MENU:

Create these categories:

1. Popular

2. Starters

3. Main Course

4. Burgers

5. Drinks

6. Desserts

Each menu item should have:

- Food image

- Food name

- Short description

- Price in KWD

- Beautiful card design

Use realistic sample Kuwaiti/Gulf restaurant menu items and realistic KWD prices.

ORDER:

- Add a prominent WhatsApp order button

- Use a placeholder WhatsApp number that is easy to replace

- Clicking it should open WhatsApp with a pre-filled order message

- Make it obvious that the customer can order from their phone

REVIEWS:

Add a beautiful "Enjoyed your meal?" section.

- "Leave us a Google Review" button

- Use a placeholder Google Review URL that is easy to replace

FOOTER:

- Restaurant name

- Kuwait

- WhatsApp

- Google Review

- Opening hours

TECHNICAL:

- No login

- No admin dashboard

- No payment system

- No database

- No customer accounts

- No POS

- No inventory

- No unnecessary features

- No complicated backend

Make all restaurant-specific information easy to find and replace in ONE simple configuration/data file if possible:

- restaurant name

- logo

- WhatsApp number

- Google review URL

- opening hours

- menu categories

- menu items

- prices

- food images

Create a polished, production-quality demo with excellent spacing, typography, mobile responsiveness and visual hierarchy.

The final result should look like a premium restaurant's real QR menu, not like an AI-generated template.
